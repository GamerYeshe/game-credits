Character, animation, furniture and environment packs — Quaternius

The following imported packs use CC0 1.0 Universal, as recorded in their included licence files:

  • Ultimate Modular Men: character parts assembled and recoloured; shading smoothed; project facial geometry, expression shapes and animation adjustments added.
  • Ultimate Modular Women: character parts assembled and recoloured; shading smoothed; project facial geometry, expression shapes and animation adjustments added.
  • Ultimate House Interior: selected furniture scaled, oriented and given project materials.
  • Stylized Nature MegaKit, Standard subset: selected plants and rocks; project tints, leaf cut-outs, foliage wind and contact bending applied.
  • Fantasy Props MegaKit, Standard subset: selected market and storage props; project materials and placement applied, including support for the supplied vertex colours.
  • Downtown City MegaKit, Standard subset: selected door frames and building textures; texture copies converted to greyscale for tintable wall finishes; project materials applied.
  • Ultimate Food Pack: apple model rescaled for the game and rendered with project materials.
  • Universal Animation Library, Standard subset: imported for Humanoid retargeting and game animation use.
  • Universal Animation Library 2, Standard subset: imported for Humanoid retargeting and game animation use.
  • Universal Base Characters, Standard subset: character evaluation assets; Humanoid retargeting, uniform height scaling and experimental surface treatments in comparisons. A permanent character switch has not been made.
  • Modular Character Outfits — Fantasy, Standard subset: outfit evaluation assets; retargeted and recoloured in comparisons, with covered body faces removed from temporary mesh copies.

Character animations and reference avatar — Adobe Mixamo

  • Source: Mixamo.
  • Usage information: Adobe's Mixamo FAQ. These assets are supplied under Adobe's terms, not CC0 or CC BY.
  • Includes the Y Bot reference avatar and standing, sitting, walking, salsa, pickup, put-down and backflip animations.
  • Changes: files renamed for the project, Humanoid retargeting configured, and poses/animation adjustments layered on top. Some clips loop or are sampled for character previews.
